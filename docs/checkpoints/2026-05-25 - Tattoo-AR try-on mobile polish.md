Key product decisions
1. Mobile is the source of truth

The desktop version can look good, but the real test is mobile.

Most users will probably enter from:

phone browser
2. The page should not over-explain Snapchat

Snapchat is only the technical layer.

The public promise is:

Try this tattoo on your body.

Not:

Use this Snapchat AR technology.
3. AR stays public, inquiry stays filtered

The page protects Nadia’s workflow:

AR is public.
Inquiry is filtered.
Nadia receives only structured intent.

Players and dreamers can try, click, share, save or follow.

Only serious users continue to the inquiry form.
